## 📖 Overview

**Neon Snake** is a modern implementation of the classic Snake game featuring a futuristic neon-themed interface, particle effects, high-score tracking, and a clean Object-Oriented Programming (OOP) architecture.

The project demonstrates the practical use of:

- Classes & Objects
- Encapsulation
- Modular Programming
- Game Development with Pygame
- File Handling
- Project Structuring

---

## ✨ Features

### Gameplay
- Smooth snake movement

## 🧠 OOP Architecture

### Snake Class
Responsible for:
- Movement
- Growth
- Self-collision detection
- Rendering

### Food Class
Responsible for:
- Food generation
- Random spawning
- Rendering

### UIManager Class
Responsible for:
- Score display
- Game-over screen
- Text rendering

### Particle Class
Responsible for:
- Background animation
- Visual effects

### Game Class
Responsible for:
- Game loop
- Event handling
- Collision management
- Score management

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/neon-snake.git
```

### Navigate to Project Directory

```bash
cd neon-snake
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

or

```bash
pip install pygame-ce
```

---

## ▶️ Running the Game

From the project root directory:

```bash
python src/main.py
```

## 🎮 Controls

| Key | Action |
|------|---------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| R | Restart Game |
| Esc | Exit Game |

---

## 💾 High Score System

The game automatically stores the highest score achieved by the player.

Stored in:

```text
data/scores.json
```

High scores persist between game sessions.
